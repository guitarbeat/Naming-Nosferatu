## 2024-10-30 - Optimize DriftWall click handler\n**Learning:** Passing an inline arrow function `(item) => handleToggleName(item.id as IdType)` to `onItemClick` in `TournamentSetup.tsx` causes the `DriftWall` component to lose its `React.memo` optimization, resulting in O(N) re-renders for all list items whenever the parent re-renders. The inline function creates a new reference on every render.\n**Action:** Use a memoized `useCallback` handler or delegate the extraction of `item.id` inside the child component, and pass the stable function reference to the `onItemClick` prop. Here, wrapping it in `useCallback` is the best approach.
