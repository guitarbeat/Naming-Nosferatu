🎯 **What:** Removed the 'as any' cast from the Recharts Tooltip formatter in TopNamesChart.tsx.

💡 **Why:** Relying on `any` bypasses TypeScript's type checking. By removing `as any` and letting TypeScript infer the parameters (`value`, `_`, `props`), we improve type safety. The payload was explicitly typed to ensure correct property access without resorting to `any`. While doing this, a Biome lint error regarding array index usage for the `Cell` key was also fixed.

✅ **Verification:** Verified by running `pnpm tsc --noEmit` and the Biome checks. All tests run perfectly and `pnpm run check` finishes without errors.

✨ **Result:** Improved type safety, maintainability, and readability.
